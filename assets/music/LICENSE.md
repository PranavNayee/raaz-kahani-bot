# Music licence notes

The bot only uses music it is allowed to use on YouTube and Instagram.

## Built in (default)
When this folder has no audio files, the bot **generates** its background music in code (`src/soundtrack.py`):
three moods (mystery, folk, suspense) built from sine pads, a drone and plucked notes. Nothing is sampled
from any recording, so there is no third-party copyright. All sound effects (crickets, wind, rain, heartbeat,
riser, impacts, whooshes, chimes, bells, thunder, footsteps, creaks) are generated the same way.

## Adding your own tracks
Put `.mp3` / `.wav` / `.m4a` / `.ogg` files here **and add one line per file below** saying where it came from
and under which licence. Only use:
- YouTube Audio Library tracks marked *no attribution required* (or add the attribution to `captions.py`), or
- CC0 / public-domain music, or
- music you made or bought with a licence that covers YouTube and Instagram monetization.

Never use film songs, commercial music or anything from a "free download" site without a clear licence.
